# Fleet Management System – C++

## Open in CLion (Windows)
1. Unzip anywhere
2. CLion → **File → Open** → select the `fleet_final` folder
3. Click **Trust and Open** when prompted
4. Wait ~2 min for the first build (downloads FTXUI from GitHub automatically)
5. Pick `app_1` or `app_2` in the top-right dropdown → press **▶**

## Controls
| Key       | Action                    |
|-----------|---------------------------|
| ↑ / ↓     | Navigate menu options     |
| Enter     | Confirm / select          |
| Esc / Q   | Go back / quit            |
| Tab       | Move between form fields  |
